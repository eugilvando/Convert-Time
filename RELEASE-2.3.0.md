O Convert Time 2.3.0 traz uma janela de conversão para Windows x64. Abra a aplicação pelo menu Iniciar ou envie uma seleção de ficheiros pelo Explorador.

* Adicione vários ficheiros, arraste-os para a janela e escolha um perfil compatível com todo o lote.
* Converta para AAC, AVI, AVIF, FLAC, GIF, ICO, JPG, MKV, MP3, MP4, OGG, OGV, PDF, PNG, WAV, WebM ou WebP, conforme os ficheiros de origem e os perfis disponíveis.
* Ajuste as opções disponibilizadas pelo perfil e escolha o destino para a conversão atual.
* Escolha o tema Sistema, Claro ou Escuro.
* A instalação usa o nome, o ícone e as preferências do Convert Time. Os créditos e a licença GPLv3 do projeto original estão no repositório.

**Instalação:** transfira `Convert-Time-2.3.0-x64.msi` e execute o instalador. Requer Windows x64 com .NET Framework 4.8. Algumas conversões de documentos dependem do Microsoft Office instalado. O MSI desta compilação pública não tem assinatura Authenticode.

**Menu do Windows 11:** as ações desta versão estão no menu clássico, acessível em **Mostrar mais opções**. A integração no primeiro menu moderno continua em desenvolvimento.
